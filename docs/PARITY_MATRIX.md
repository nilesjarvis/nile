# Android-to-iOS parity matrix

> Acceptance source of truth: AGENTS.md and IOS_PORT_GOAL.md. The historical
> [`IOS_NATIVE_DESIGN.md`](IOS_NATIVE_DESIGN.md) records a branch-era decision
> and current implementation divergences; it does not replace the pinned Android
> app-owned visual target. A red strict comparison is incomplete parity, not an
> accepted redesign result.

## Status definitions

- **Verified foundation**: implemented and covered by focused current tests, but
  still subject to the final full-lab rerun.
- **Partial**: useful production behavior exists, but the Android outcome is not
  complete.
- **Not started**: no parity implementation exists.
- **Blocked**: external evidence or authority is required; none are currently marked.

The source column always refers to the immutable Android commit documented in
`AGENTS.md`.
